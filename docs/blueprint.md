# **App Name**: Sixth Hour Cafe Queue

## Core Features:

- Order Submission: Customers can submit their drink orders with their name on the customer-facing iPad.
- Order Display: Display submitted orders on the staff-facing iPad, showing the customer's name and selected drinks.
- Real-time Updates: Orders update in real-time on the staff-facing iPad as they are submitted.
- Menu Management: On the staff iPad, allow changing the available drinks or marking them as out of stock. The current drinks are: Maple Matcha Latte, Dalgona Wipped Coffee, London fog, apple cider chai

## Style Guidelines:

- Text color: #1800AD
- Background color: #F6F4F0
- Font: ff providence sans
- Use white doodle-style icons, mirroring the style of the coffee bag logo, for drink categories.
- Clean, uncluttered layout with ample spacing to ensure readability and ease of use on the iPad screens.
- Subtle animations on order submission and updates to provide a visual cue and enhance user experience.
